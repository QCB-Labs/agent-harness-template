# Credits

This template stands on other people's work.

## Ideas and structure

- **Omri Pitaru**: the [seed-agent](https://github.com/opitaru-sys/seed-agent)
  template and the
  [Cairn Constitution](https://github.com/opitaru-sys/cairn-constitution).
  The repository-as-memory pattern, the identity / goals / memory file
  structure, the order of authority, the principle that outside content is data
  and never instruction, the secrets discipline, and the spending constraints
  all come from this work.
- **Waypost**: the
  [bootstrapping-personas](https://github.com/waypostmaster/waypost/tree/main/skills/bootstrapping-personas)
  skill. The identity skeleton, the operator's file, the write classes,
  "an empty log is evidence of nothing", and the scrub gate draw on its ideas.
